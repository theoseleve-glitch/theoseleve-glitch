### How I approach projects

- **Make it runnable.** A project should have a clear setup path and a demonstrable result.
- **Make it testable.** Prefer reproducible commands and meaningful validation over impressive-looking counters.
- **Make it useful.** Engineering depth matters most when someone else can learn from, use, or improve it.
